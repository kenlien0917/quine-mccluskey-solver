# Source and scope

This repository presents logic design coursework from the supplied personal archive. The submitted implementation is preserved byte-for-byte in `src/QM.cpp`; its SHA-256 is recorded in `source-manifest.json`.

The original submission directory and personal student identifier have been omitted from the public manifest. Drafts, Visual Studio caches, binaries, reports and assignment PDFs are excluded.

The demo and verification harness are added during portfolio preparation. They call the submitted algorithm without rewriting it. This is coursework, not a claim that every scaffold, API signature or algorithm was invented by the repository owner. The archive does not establish the authorship of every comment or scaffold; no new license grant is added.
